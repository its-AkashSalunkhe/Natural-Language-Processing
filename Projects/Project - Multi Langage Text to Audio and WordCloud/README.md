# 🌍 Globalize — Multilingual NLP Streamlit Application

A multilingual Natural Language Processing (NLP) application built with **Streamlit** that can detect the language of a paragraph, translate it into multiple languages, generate a **Word Cloud**, and **read the translated text aloud** using text-to-speech.

## 📌 Overview

Globalize is an end-to-end NLP application that combines **language detection, machine translation, text-to-speech, and word cloud visualization** into a single interactive interface. It demonstrates how multiple NLP libraries can be integrated to build a practical multilingual text processing tool.

## ✨ Features

* 🌐 Automatic language detection
* 🔁 Translation into multiple selected languages
* 🔊 Text-to-Speech (Read Aloud)
* ☁️ Word Cloud generation
* 📊 Interactive Streamlit interface
* 🧠 NLP tokenization using NLTK

## 🛠️ Technologies Used

## 🚀 How to Run

1. Clone the repository
2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the Streamlit application

```bash
streamlit run nlustream.py
```
